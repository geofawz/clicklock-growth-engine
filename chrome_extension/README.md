# 🚀 Meta Ad Library Scraper Pro | كاشف إعلانات المنافسين الذكي

أداة وإضافة كروم مخصصة **(Chrome Extension - Manifest V3)** مصممة خصيصاً لسحب وتفكيك وتحليل إعلانات المنافسين من **مكتبة إعلانات فيسبوك / ميتا (Meta & Facebook Ad Library)** وتصديرها مباشرة إلى ملفات **Excel (.xlsx)** و **CSV** و **JSON** نظيفة ومنسقة، مع ميزة التمرير التلقائي الذكي **(Auto-Scroll)** وفك تشفير الروابط وتنزيل الفيديوهات والصور.

## 🛠️ طريقة التثبيت في متصفح جوجل كروم (خلال دقيقة واحدة)

1. افتح متصفح **Google Chrome** (أو Brave / Edge).
2. في شريط العنوان، اكتب: `chrome://extensions/` واضغط Enter.
3. قم بتفعيل خيار **"Developer mode" (وضع مطور البرامج)** في الزاوية العلوية اليمنى.
4. اضغط على زر **"Load unpacked" (تحميل إضافة لم يتم حزمها)** في الزاوية اليسرى.
5. اختر مجلد الإضافة:
   ```
   E:\vs project\clicklock\chrome_extension
   ```
6. مبروك! ستظهر الإضافة فوراً في شريط أدوات كروم بشعار Clicklock المميز.

## 📖 كيفية الاستخدام خطوة بخطوة

1. ادخل إلى **مكتبة إعلانات ميتا**:
   [https://www.facebook.com/ads/library/](https://www.facebook.com/ads/library/)
2. ابحث عن أي منافس (مثلاً: *Vacation Skincare*, *Dior*, *Bottega*, أو أي متجر سعودي).
3. ستلاحظ ظهور زر دائري أنيق عائم في أسفل يمين الصفحة بعنوان **"Meta Ad Scraper"**.
4. اضغط على الزر لفتح لوحة التحكم الجانبية:
   * ⚡ **Scrape Visible:** لسحب الإعلانات الظاهرة حالياً على الشاشة بضغطة زر واحدة.
   * 🚀 **Auto-Scroll & Scrape:** لتشغيل النزول التلقائي وجمع 50 أو 100 أو كافة إعلانات الصفحة دون أي مجهود.
5. بعد اكتمال الجمع، اضغط على **"📗 Excel (.xlsx)"** لتحميل جدول البيانات المتكامل فوراً.

## 📊 البيانات المستخرجة في ملف الإكسيل (Columns Schema)

1. **`Library ID`**: رقم تعريف الإعلان الفريد في ميتا.
2. **`Status`**: حالة الإعلان (Active / Inactive).
3. **`Started Date`**: تاريخ انطلاق الإعلان (مثال: Apr 14, 2026).
4. **`Active Duration`**: إجمالي فترة النشاط بالساعات والأيام.
5. **`Ad Versions Count`**: عدد النسخ المشتقة من نفس النص والتصميم (مثال: 2 ads).
6. **`Advertiser / Page Name`**: اسم صفحة المعلن / البراند.
7. **`Platforms`**: المنصات التي ظهر فيها الإعلان (Facebook, Instagram, Messenger, Audience Network).
8. **`Ad Primary Copy / Text`**: النص الإعلاني الكامل (الكابشن).
9. **`Media Type`**: نوع الإعلان (Video, Image, Carousel).
10. **`Headline / Title`**: العنوان البارز أسفل الميديا.
11. **`Description`**: الوصف والنبذة الفرعية.
12. **`Call To Action (CTA)`**: زر اتخاذ الإجراء (Order now, Shop now, Get offer, اطلب الآن).
13. **`Clean Destination URL`**: رابط صفحة الهبوط الحقيقية المفكوكة من تشفير فيسبوك.
14. **`Video Download Link`**: رابط الفيديو المباشر لتحميل المحتوى بجودة أصلية.
15. **`Image / Media URLs`**: روابط صور الإعلان وبوسترات الفيديو.
16. **`Page Profile Pic URL`**: صورة شعار المعلن.
17. **`Scraped Timestamp`**: التوقيت الزمني لعملية السحب.
