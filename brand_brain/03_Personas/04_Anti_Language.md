# 04. Anti-Language | الكلمات والمصطلحات المحظورة في الخطاب

للحفاظ على هالة الفخامة والرقي، يحظر تماماً استخدام الألفاظ التالية في كافة الحملات والردود:

| الكلمة الممنوعة ❌ | البديل المعتمد الفاخر ✅ | السبب والدافع |
| :--- | :--- | :--- |
| تقليد / صيني / كوبي | **ماستر كواليتي (1:1) / قطع مطابقة للأصل** | كلمة تقليد ترتبط بالرداءة والبلاستيك الرخيص وتثير الخجل الاجتماعي. |
| رخيص / أرخص سعر / بلاش | **سعر ذكي / قيمة حقيقية / توفير استثنائي** | كلمة رخيص تقتل القيمة النفسية للقطعة الفاخرة. |
| حرق أسعار / عروض كنس | **إصدارات حصرية / عروض الموسم الخاصة** | لغة الحراج والأسواق الشعبية تدمر هيبة البراند. |
| شنط بناتية عادية | **قطع الهَبّة المختارة / تصاميم أيقونية** | تعزيز الارتباط بالتريند والمكانة الاجتماعية. |
| بضاعة / ستوك | **كولكشن / تشكيلة فاخرة / قطع محدودة** | الارتقاء بالمعجم التجاري ليعكس روح البوتيكات العالمية. |
